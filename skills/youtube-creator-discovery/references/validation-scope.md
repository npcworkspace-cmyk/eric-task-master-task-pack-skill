# 公共发行与验证范围

公共包版本 0.1.5。首次接入公共仓库时，在本机 0.1.4 完整单元上补充发行元数据、MIT 许可证和本说明，统一 LF 换行。浏览器逻辑仍为 0.1.3，离线处理器逻辑仍为 0.1.4；组件版本与整包版本分别记录。

## 离线验证

`node --test scripts/behavior.test.mjs` 使用合成页面和账号，覆盖稳定身份排重、基线、溢出、来源归属、失败恢复、Shorts 与精确当前视频作者、四种审核状态、判断证据约束、身份补查队列和冻结样本保护。测试不会登录网站或访问真实账号。

仓库集成测试验证确定性 ZIP、清单一致性、Unicode 和空格目录安装、脱离仓库工作目录的实际处理器 CLI，以及安装副本的全部 14 项行为测试。三系统 CI 和 Release 均运行这些检查；具体通过范围以该提交或 tag 的运行结果为准，不能用本地 Windows 通过代称其他系统已通过。

## 历史浏览器证据

本地历史任务曾验证频道和视频搜索、播放页推荐、列表作者、新版 Shorts 卡片与当前视频作者解析，并回放两个不同主题的归档证据。本次公共发行不重新采集 YouTube；LF 规范化会改变字节哈希，旧本机文件哈希不能直接指代发行文件。

这些历史观察只说明当时的页面、Profile 和有限任务范围。不保证当前平台可用、跨系统真实 Chrome 兼容、特定入口命中率或完整商务资格。每个新任务先按已授权范围小批校准，遇验证和访问限制保留进度并交接。

## 业务与交付边界

处理器对账 Agent 已提供的判断，不代替内容、原创性、受众或商务资格审核。发现数量达标、声明样本审核完成、全池审核覆盖和必要条件判定完成分别报告。待补证据不是不符，未审不是待补。身份队列和审核待办不会自动派发浏览器工作。

客户条件、账号名单、Profile、原始页面、工时和历史质量报告留在任务目录。公共包只有通用代码、说明、合成测试和发行元数据；审计和 CI 证据另存于任务或 PR，不混入安装载荷。旧本机 0.1.4 可作为回退版本，公共 ZIP 安装按仓库安装器保留原副本。
