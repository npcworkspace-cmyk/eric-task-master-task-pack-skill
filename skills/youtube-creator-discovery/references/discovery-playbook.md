# YT 入口与证据语义

2026-09-07 更新。入口选择依赖真实 Brief、Profile 和当时 UI，不把历史产出或界面文案当平台保证。本 Pack 从当前挂载的卡片取证，支持的选择器来自 Windows Chrome 实页观察。

| 入口 | 怎么取候选 | 可证明什么 | 主要缺口 |
|---|---|---|---|
| 场景/问题视频搜索 | 查询 → 视频卡 → 作者频道 ID | 该作者有一条在此查询下出现的内容及标题/摘要 | 搜索结果混题、一次命中、热门内容偏差；持续主题另查 |
| Shorts 搜索 | 当前短视频过滤器 → Shorts 卡片 → 精确视频作者补查 | 短视频作品与频道的明确归属 | 新版卡片常无作者；未解析视频不计频道，补查成本不能省略 |
| 品牌/型号视频搜索 | 参考中真实品牌/型号 → 评测或使用查询 → 作者 | 内容与品牌/产品之间的发现线索 | 提及、affiliate、自有品牌、广告、独立评测分开 |
| 频道搜索 | 同源词 → 搜索过滤器“频道” → 频道卡 | 名称、简介或可见频道卡及稳定 ID | 品牌、店铺、休眠或普通用户混杂，必须补主页 |
| 播放页默认推荐 | 已审种子的真实作品 → 右侧挂载视频 → 作者 | 此会话在这条视频旁出现推荐 | 个性化与历史信号影响大，不能当相似作者认证 |
| 播放页主题筛选 | 相同作品 → 实际可见的“相关内容”或主题 chip | 当前筛选下观察到的推荐 | chip 可能缺失，仍可能偏题；缺控件记未可用 |
| 播放列表作者 | 相关列表入口 → 列表内每条视频的作者 | playlist → video → channel 的明确来源边 | 整理者不等于作者；单频道列表往往只有一个作者 |
| 描述提及/署名 | 本人作品公开说明中的明确频道链接 → 被指名主页 | 被链接或被提及的对象及原文 | 只出现链接先记 reference_only，核实本人后才计采集 |
| 真实标签查询 | 本人作品出现的 #标签 → 标签搜索或已观察标签页 | 标签下出现的作品与作者 | 同标签不证明同主题、同受众或同国家 |

频道主页的 Videos、Shorts、Streams 分开采样。热门、置顶、最近上传与搜索命中不能互换。`/videos` 样本无需混入 Shorts 当作同一表现分母。页面已加载但日期未知的内容保留原文；不要猜出精确发布时间。

Shorts 支持普通视频卡中的 `/shorts/` 链接及实际挂载的 `ytm-shorts-lockup-view-model`。搜索卡没有作者时先保留 video ID，再打开此视频读取匹配的公开 `videoDetails`。不要用搜索结果页、播放列表整理者或其他推荐视频的作者补位。`contentFormat=shorts` 只证明入口形式，不能证明原创实拍或评测质量。

派发作者补查前先按 video ID 去重，与整个已存作品池对账，跳过当前源卡或其他观察已确认作者的记录。`process.mjs` 的 `identity-queue.json` 将未解析、已归属和归属冲突分开，保留所有来源；Agent 再选择有限动作预算。不要为凑补查数量重复打开已归属视频；额外做身份抽检时单列目的和成本。

## 低成本的对照方法

同源查询比较“视频作者”和“频道结果”；同一作品比较默认推荐和主题 chip；交替先后次序，保留各动作的同等预算与缺失入口。搜索列表再进具体列表的前置成本分摊或单列，不能只计算点击列表后的耗时。

正式贡献归最早有效发现，易受先后顺序影响；另外给每路线对固定基线的独立去重集合。小样本和适应性扩量分开，不能拿不同预算下的首次贡献说因果胜负。

入口预算由本轮已审结果调整，不把某一品类的品牌搜索或默认推荐收益写成永久优先级。新方向先小批观察主题漂移、品牌店铺比例和未知作者成本；成批集中审核后，再放大有持续内容和明确父线索的查询。单作者播放列表不适合继续为找新作者深滚；先确认多作者迹象及列表主题，再增加预算。

“搜索扩量”和“已审种子沿明确关系展开”分别验收。后者需真实 seed → 内容/列表/提及 → 新作者证据；只生成下一轮动作不算已经执行裂变。要比较每分钟有效账号，使用同一组已完成审核的候选及其完整成本；缺 Agent 审核时间就只能报告浏览器成本，不能用未审池人数或抽样推算人数充当实际有效产出。

冻结实际候选框后抽样补主页，再按同一标准判断主题、角色和持续内容。目的性挑选的高潜账号另列，不能混进随机/哈希样本抬高通过率。来源间重叠的对象可在多个路线样本中出现，但唯一审核人数另报。

若要报告整池命中率，另从正式池等概率抽样，或按完整分层权重计算。路线等额样本合并后的未经加权通过率，只描述该审核样本，不代表正式池。主题命中、持续评测、Shorts 作品证据与主体角色分别记录，避免用一次产品提及替代持续评测。

未完成身份解析、缺少作者卡、加载失败、列表结束、预算停止分别统计。只有卡片的对象可做名称/标题初筛，不写成已深审。描述自称“亲测”但同时声明资料来自假设时，保留矛盾证据，限制展开用途。

从标题提取品牌时核对完整品牌词及对应作品，避免子串误命中；例如品牌 Lectric 不能由普通词 Electric 推导。主题背景、原文提及和 Agent 推导分别标记。若收尾才发现来源绑定错误，保留执行时原记录，追加更正说明及真实支持证据，不改写历史动作或虚构当时已使用的来源。

完整品牌词也可能与电影、人物、食品或其他行业同名。查询优先绑定参考中已核对的具体品类或型号；若发现大量跨行业结果，用相同预算比较原查询与加品类的查询，再决定下一批。比较需保存原快照、卡片样本和相关性判断；卡片相关率不等于作者资格命中率。保留原批次的误召回与实际成本，修正不能追溯改写原有统计。

## 官方文档

- [高级搜索过滤器](https://support.google.com/youtube/answer/111997?hl=en)：官方支持按视频、Shorts、频道和播放列表等类型筛选。控件文字及实际返回仍需观察。
- [推荐机制](https://support.google.com/youtube/answer/16089387?hl=en)：观看/搜索历史和当前内容等信号会影响推荐。当前 Profile 的路线结果不能外推所有账户。
- [Data API Search](https://developers.google.com/youtube/v3/docs/search/list)：官方 API 可作为具有权限和预算时的补充；regionCode/relevanceLanguage 不是作者或受众所在地证明。
- [API 变更记录](https://developers.google.com/youtube/v3/revision_history)：`relatedToVideoId` 已停止支持，不能用过时接口承诺推荐递归。公开观看量规则会更新，跨时段或形式比较前检查当日定义。

本 Pack 本轮不使用付费 API，也不要求导出浏览器凭据。没有授权或额度时不购买；存在官方项目时按当日配额核查，不把历史配额数字写死。
