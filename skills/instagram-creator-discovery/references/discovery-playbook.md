# Instagram 发现与审核手册

## 参考研究与种子准入

每条参考保存原始链接、用户/模拟参考类型、实际作品与作者、实体角色、观察范围、主要主题、产品场景、形式与风格证据、真实标签、关系、负向边界、查询建议及未知项。查询区分原词与分析推导，不从人物外貌推断身份，不从地点/语言推出受众国家。

先分析少量有区别的参考再扩批。参考为作品时核对 shortcode 和当前作者区域，避免把预加载的下一条 Reel 作者带入。元数据里的 `pageText` 不是 caption；封面/alt 不是完整轮播或视频。若指定全时间窗口，需要可验证分页/结束边界；内置采集器的有限滚动只提供部分覆盖。

角色可用个人、创作团队、品牌、店铺/服务、社区/机构、媒体/策展、未知；主题可用核心、相邻、无关、证据不足。角色和主题分别判定。只有一条产品帖可证明一次匹配，成为核心种子还需持续内容与实际创作主体证据。持续性按本轮 Brief 定义，不固定帖子数或题材。

## 入口排查表

每轮保存实际 `surface + seed/query + filters/sort + visible result type + budget + evidence + outcome`。状态分 `documented / observed / batch_measured / unsupported / blocked / not_tested`，可用性附时间和环境；文档存在、UI 观察、批次成功是不同证据，不能互相替代。

| 入口/下一跳 | 适合的起点 | 必须保留的语义与限制 |
|---|---|---|
| 普通主页 Similar / 类似账户 | 已审个人或团队 | 在该主页看到的推荐卡片；不是 Following、合作、同受众或 Marketplace 推荐 |
| Following | 已审主体；有具体范围的中转 | 当前可见关注关系；可能混合私人社交、品牌、店铺与人物，必须集中审核 |
| 主页 Posts / Reels | 参考、品牌、个人 | 作品清单用于主题和关系；主页作者本身不因再次读取变成新增 |
| 关键词搜索 → 作品 → 作者 | 产品、场景、身份自述、形式词 | 记录实际结果类型与查询；账户建议和作品结果不能混统计 |
| 标签页 → 作品 → 作者 | 实际参考标签与有来源的扩词 | 同标签不是定位/受众证明；缺少日期过滤就不声称按时间全量 |
| 品牌或种子 Tagged → 作品 → 作者 | 品牌、活动、机构 | 被标记与创作/付费合作分开；只看 Tagged 网格不能确认关系性质 |
| Collab 可见共同作者 | 真实作品 | 同一作品链接多个作者；折叠“和其他人”未展开保留部分覆盖 |
| 明确署名 / credit → 指名主页 | 已审作品文字、图片或可见作者署名 | 带源作品、父种子、关系与原始证据；普通 @、评论、转载与作者分别记录 |
| Reposts / 转载入口 | 可见转载页 | 回到原作品确认作者；转载者不是原作者，界面未实现就记待验证 |
| Reel 播放页 / 推荐流 | 当前可见作品 | 必须隔离当前作品；无限推荐流需独立有界适配和测量，不能沿用网格路线产能 |
| 音频、Remix、效果等作品关系 | 页面上真实可点的关系 | 存在性和含义需当前观察；仅题材/音频相同不证明合作，不是内置必跑路线 |
| 地点/Map、活动入口 | 位置明确的内容目标 | 可访问性和地域覆盖单独验证；内容地点不是作者或受众所在地 |
| 评论者 / 点赞者 / Followers | 任务确实需要的相关关系 | 普通互动者不自动是红人；未实现/未测试就留验证队列，不收无关个人信息 |
| Creator Marketplace 搜索/属性筛选 | 已有可见且获授权的品牌功能 | 记录实际过滤/排序及受众字段定义；权限与菜单因账号而异 |
| Marketplace Similar creators | Marketplace 中的可用种子 | 单独 surface/route；不得和普通主页 Similar 合并收益 |
| 品牌兴趣/提及推荐、Partnership Ads Hub | 用户已授权且页面可见的品牌入口 | 相关有限集合，平台推荐与效果预测属于 platform_claim，邀请和广告授权另需授权 |
| 官方 API / 商业数据接口 | 已有明确接口权限与适用许可 | 按真实 API 契约；公开可见不等于可通过任意 IG API 获取，不能导出登录凭据 |

上述是规划排查范围，不是所有路线的采集器或同预算压测声明。普通网页已测路线与本版支持集合见 [运行契约](runtime.md)。搜索/音频/Map 等新 UI 路线应先做有限验证再决定实现，不对每个种子强制跑全集。

## 路线分配

个人/团队种子优先校准 Similar 与 Following 两条批量入口；品牌、店铺、媒体和社区优先用明确作品作者/署名及限定场景。内容路径常有较强的主题来源，是否更有效要同时看候选量、审核后的种子收益和成本。

每轮由预算选择小批校准规模，不固定 2,000 个、120 卡片或滚动次数。比较两条路线时尽量对同组已审种子使用相同上限，交替先后次序，保留每个种子的实际观测量。校准后扩量属于不同阶段，不能混成严格配对结果。

入口缺失/失败时调整仍获授权且可用的路线预算。失败成本保留；不能把失败加载解释为推荐池为空或无相关人物。重复饱和但没有资格审核时，只能说召回趋于饱和，不能说已找不到合格红人。

## 集中审核与补证

先清理背景种子、仅引用对象、无效观察与重复，再审语义。卡片显示名/用户名只供排序；卡片初筛 (`triage`) 与主页语义审核 (`profile_review`) 分层。主页结论应引用 bio、已加载作品及观察时间；私密、未知日期、未加载网格留下缺口。多审核者共用 rubric 和相同类型判例；发现矛盾保留原记录、复审理由和修正，再重算所有受影响统计。

三项结论分开：

- **目标匹配：** 角色、主题持续性、产品/场景、形式/风格、语言与要求的受众证据。
- **商业资格：** 仅按 Brief 检查规模、活跃、竞争排除、报价、时程、合作意愿及授权；没有要求记 not_required，有要求缺证据记 unknown。
- **展开价值：** 核心个人/团队、限定中转、待补或停止；中转需写允许的下一跳、父种子和证据，不能只写“相关的都展开”。

同一实体可以商业不符但仍是有价值的中转；任何主题种子不等于商务通过。口播、镜头和审美要求必须实际观看对应媒体，记录 inspection_mode、时间点和 permalink；元数据审核只给元数据支持的判断。

简介所在地、content location、caption language、spoken language 与 audience geography 分字段。当前粉丝、作品互动、公开商务入口按时点保存；不推断受众比例、报价、授权或转化。合作标记是有限事实，Logo、tag、被提及和付费关系不能互换。

## 抽样与指标

先冻结已观察候选框及哈希，再抽路线样本。样本注明阶段、路线、种子、抽样方法、应审/已审/未知、真实分母与重叠账号数。可复现哈希抽样只代表该候选框，不代表全 IG 随机抽样。

名称/场景线索挑出的目的性补查队列单独报告；它的命中率不能作为路线总体质量。主页语义审核优先于卡片初筛，不被较晚的低证据 triage 覆盖；同层按实际证据时点，再审核时间决策。保留历史判定与纠错关联。

Reel、单图和轮播分别算指标。缺少 views 记 null；明确 likes/comments/followers/views 的分母、窗口、样本及排除。置顶/热门/近期样本不能混称常态表现，Collab 的同一作品不重复累加为独立成果。
