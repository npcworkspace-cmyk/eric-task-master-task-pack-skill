# 实现与证据边界

首个带版本的安装包：1.0.0，2026-09-07。前版为无版本业务指南，仅含入口、手册、数据契约和 UI 元数据；本版新增执行器、离线对账与独立测试。Node 内置模块，无平台 SDK、登录凭据或客户数据；浏览器外部依赖 Eric Task Master 与用户的 Chrome 环境。

## 历史任务证据

2026-09-06 的五个模拟参考、两轮采集，在指定的一个登录环境下形成每轮 2,000 个正式账号，合计 4,000 个规范 handle；其中 347 个正式主页做过语义审核，其余为初筛层。这些数量描述那次任务，不是本 Skill 的默认目标、资格保证或新安装版本测试数据。

历史批次量化覆盖普通主页 Similar、Following、关键词/内容、标签、Tagged/作品作者、Collab 作者和带证据署名指名主页等七类路线。无限 Reels 流、Marketplace、音频、Remix、Map、评论者和点赞者未完成相同预算的量化测试。入口研究表包含更多可能入口，不能称为全部批量能力已验证。

当时 Similar 在部分配对动作中较快，后段又出现可见“加载失败”；Following 保持召回，但混合多种实体角色。历史效率不作为通用参数或单一路线优胜结论。主题质量、代表性和完整项目成本均有采样边界。

可复用修复来源：当前 Reel 与作者隔离、主页目标复核、私密/加载缺口分类、动作键包含实际工作规范、候选与背景分开、带来源的指名主页、审核证据优先级、基线与溢出、达标未启动、有限诊断及路线停用。

## 本版的验证声明

`collect.mjs` 从历史实测模块提取并加固，但其泛化后的代码应以本次随包审计报告中的验证结果为准。历史成功不自动传递给新代码。离线模拟测试只检验预算、解析边界、日志/恢复、停止与计数，不证明 Instagram 当前界面或所有语言可用。

`ig-audit.mjs` 只做数据的确定性对账和已有审核的合并，不自行证明网页真伪、主题持续性、完整音视频原创、受众质量或商务资格。结构校验通过不等于语义通过。

首次在新语言、UI 或机器使用时，先在任务已授权范围内做有界校准，保存当时模块哈希和字段覆盖；入口不可见时明确失败原因，适配前不能靠放宽选择器猜作者。不得因安装文件可复制就声称跨操作系统真实浏览器验证。

完整历史账号、Profile、原始页面与客户策略留在原任务交付中；可移植安装包不包含它们。发布报告另外列出候选、安装、ZIP 哈希与实测/未测范围，避免自包含哈希循环。

## 公共发布适配 1.0.1

1.0.1 将原通用模块接入公共 Skills 仓库，补充发行元数据和许可证，统一 LF 换行，并明确标注测试中的合成示例。行为测试与隔离安装纳入仓库 CI/Release；具体系统验证以对应提交和 tag 的成功运行记录为准。原 1.0.0 的本机验收记录不被改写，新版本仍未作新的真实 Instagram 采集验证。
