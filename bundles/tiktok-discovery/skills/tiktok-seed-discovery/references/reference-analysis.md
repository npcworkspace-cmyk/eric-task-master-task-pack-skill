# 参考链接深剖与覆盖

## 固定研究窗口，明确参考含义

首次 intake 保存 UTC 截止时点 `asOfUTC`，以日历月回退确定窗口起点，默认 6 个月，全年为 12 个月；恢复同一研究沿用已保存窗口。用户给具体日期时采用该范围。窗口不是滚动时“当前时间减 180 天”的浮动条件。

客户为每条参考给出的类型只表示用途：

| 参考类型 | 用途 | 不能自动得出的结论 |
|---|---|---|
| `competitor` | 研究竞品账号、竞品合作线索或竞品相关创作者 | 其出现的所有品牌/账号都与竞品付费合作 |
| `brand_partner` | 客户声明已合作，用于提炼可复制的人群与内容方式 | 平台公开证据已验证合作、销量或满意度 |
| `style_reference` | 提炼希望的类别、场景与表现形式 | 其所在地、粉丝量或商业条件必然符合本轮要求 |

保存客户备注为客户输入，与公开观察来源分开。主页/作品解析后保留原始 URL、规范 URL、平台作品/账号 ID 和 handle；同一作者多条参考只采一次，参考用途不丢失。TikTok 之外的链接不静默交给其他平台接口；先保留待处理或向客户索要对应 TikTok 链接。

品牌主页可以提供品牌自身话题、合作披露和被提及达人，但本身不是个人红人。对其提及的账号按各自来源入候选，不能把普通 @ 对象默认成合作达人。具体作品必须确认作者再展开本人时间线；仅凭标题或显示名匹配不足时保持未确认。

## 采集窗口内全部可访问作品

“全量”的含义是目标账号在当前权限下窗口内全部可访问的作品。执行器应持续枚举真实主页时间线/分页，保存视频与照片帖，按稳定作品 ID 去重；窗口内每条可读作品保留：

- 作者/作品 ID 与 URL、发布时间原文与规范值、观察时点、置顶状态和媒体类型。
- 文案、真实标签、@ 对象、音乐/集合等实际可读链接、品牌/产品字样和商业披露。
- 可见播放、点赞、评论、分享等指标及缺失状态；指标观察值不是账号后台统计。
- 当前参考来源、页/批次/动作、原始证据位置以及解析/采集错误。

仅将当前页面真实作品与正常加载响应中能可靠配对的数据合并。不能用未匹配的推荐响应、搜索结果或缓存记录补造成本人完整时间线。

置顶项不能证明时间顺序，也不能以一条旧置顶作品作为停止边界。先区分置顶与普通序列；若时间排序不可证实，继续至真实列表结束或明确预算边界，报告覆盖缺口。日期未知的作品保留待判定，不能为提高完成率丢弃或假定在窗外。搜索命中本人作品只能补样本，不可代替完整主页枚举。

只有达到可靠时间边界/真实列表结束并检查了置顶、未知日期、加载缺口时，才能标记相应范围完成。分页失败、访问限制、预算耗尽、未枚举、日期未定都进入 coverage；分别报告实际观察数、窗内数、窗外数、未知日期数、缺失字段和停止原因。取得 100 条或滚动若干屏不构成全量证据。任何完成状态以运行库实际 coverage 字段与原始观察为据。

## 标签、品牌与内容关系

技术提取先保留全部观察值和原文出处，再规范化、聚类与 AI 审阅。原始标签与推导查询分列；大小写合并不丢原拼写。同一品牌名称别名合并要保留证据，不能把常见词硬识别成品牌。

品牌关系至少采用以下区分，每个判断附本人原文/公开披露、作品/主页来源和观察时间：

| 关系 | 可接受的证据含义 |
|---|---|
| `mention` | 实际出现名称或 @ 品牌，但无更强商业证据 |
| `product_use` | 可见或明确自述使用、演示、评测产品，付费关系未确定 |
| `gifted` | 本人明确称赠送、公关寄送、gifted 等 |
| `paid_partner` | 平台付费合作标识或本人明确付费合作披露；泛 `#ad` 未能归属具体品牌时保持归属未知 |
| `self_brand` | 本人明确拥有/经营该品牌或官方身份有证据 |
| `unknown` | 名称、关系或品牌归属无法确认 |

这些是证据类型，不是从低到高自动升级的分数；同一品牌多次关系分开保留。客户声明的“已合作”可以保存为客户来源，但不冒充平台证据。品牌购物链接或折扣码可以是商业线索，不能直接证明成交、付费合作或收入。

## Agent 必须完成的语义审核

`reference-analysis.mjs` 组织文案、标签和关系候选；程序不替 Agent 完成理解。Agent 分批读取原文和必要视觉样本，形成每个参考的档案：

1. **主题与类别**：主次内容方向、持续出现的场景、不同内容方向的证据覆盖。
2. **身份与地域**：本人明确自述、创作者所在地与目标受众分别给已证实/相反/未知；不从外貌、孩子出镜、语言或 IP 推断。
3. **内容形式与风格**：演示、讲解、对比、日常叙事等文本可支持的结论；视觉感受需真实观看并保留样本，未看部分保持未知。
4. **品牌与账号关系**：按上述证据类型逐项记录，并识别品牌主页/普通用户/创作者，不能把提及网络当合作网络。
5. **活跃度与指标**：只有日期和采集覆盖足够时计算窗口内频次；互动注明指标公式、可用样本数、日期覆盖和缺失，不能声称粉丝真实性已认证。
6. **可迁移线索与负向边界**：哪些标签、品牌、场景、身份表达值得用于搜索，哪些是偶发、泛词、偏题、品牌官方或其他不适合的方向；每项附原文证据或注明推导。

已审核结论必须符合执行器的证据校验结构，reviewFile 带当前 briefId 和冻结窗口 start/end，防止跨任务审核污染。缺审、引文不存在或来源作者不匹配时保持待评审。AI 结果与原始作品并存，不覆盖原始数据。产物应支持重新审核与复盘，而不只是一段无法复核的画像总结。

## 衔接种子发现

把通过审核的标签簇、场景、品牌/产品、身份表达和风格线索转成查询计划，保留 reference → evidence → query 的链条。种子发现按普通视频搜索批量拿新作者，再走 [集中审核](shared-tail.md)。没有参考证据的扩展表达可作为假设试验，但必须和已观察事实分开。

只有参考深剖已经实际执行并完成 AI 审阅的部分能计入“已研究”。部分参考不可访问时先利用已取得的可靠材料继续有限发现，报告缺口；不能把新搜索的结果倒填成最初参考的分析。
